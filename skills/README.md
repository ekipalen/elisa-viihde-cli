# Skills

This repository includes reusable AgentSkills for the Elisa Viihde CLI.

These skills are meant to be a starting point.
You can use them as-is, or copy and adapt them for your own setup, preferences, and workflows.

## Available skills

- `elisa-viihde`
  - General-purpose skill for browsing guide data, searching programs, checking recordings, and recording programs with the Elisa Viihde CLI.
  - Designed as a reusable template rather than a user-specific setup.

## Suggested approach

Use the base skill first.
Then customize its behavior with your own local preferences, favorite channels, genres, and recording habits.

See:
- `elisa-viihde/SKILL.md`
- `elisa-viihde/references/preferences.template.md`
